Frequently asked questions

Where is my data?

In a folder you choose: on your PC or on a network share (UNC path or mapped drive). Human-readable JSON files, one per project. Nothing is sent to us or to third parties: the app has no server and collects no telemetry.

Does it work offline?

Yes. Everything happens on the local network. Internet is only needed to download updates and, if you use it, for the Google Drive feature. License verification is local too.

How do we share it with colleagues?

Create the workspace in a server folder as “Shared on the network” with a password. Colleagues install the app, open the same folder and enter the password once. From then on everyone's changes show up on the other PCs within seconds.

What if two people edit the same project?

Every change re-reads the file from disk, applies the edit and writes atomically (temporary file plus rename). Changes add up. If a colleague touched the project you are looking at, the row flashes and a notice tells you who.

What happens when the subscription ends?

The workspace goes back to the Free plan: you keep using the app and the data stays where it is, but Team features (seats beyond the third, audit log, export, backups, Drive) switch off until you renew. Subscriptions are yearly (or monthly) and include every update.

Do I need a license per PC?

No: one license per workspace, i.e. per shared folder. It covers every member up to the plan's seats. Several offices with several folders need several licenses, or the Business plan with more workspaces.

Is it GDPR compliant?

Data never leaves your infrastructure and the app collects nothing beyond the Windows user name and PC name used to sign changes. There are no third-party transfers to document. See the privacy notice (Italian).

Windows shows “Windows protected your PC” on install.

That is SmartScreen, which distrusts programs it sees for the first time. Installers are digitally signed and the warning fades as reputation grows; meanwhile choose “More info → Run anyway” after checking the SHA-256 published with the release. You can also install with winget.

Can I import what I already have?

Yes: from a project's “Export or print” menu choose “Import from CSV or Trello”. A CSV from Excel (Title, Priority, Due date, Label… columns) or a Trello board JSON export become items, with the right labels and buckets. The app's own CSV export re-imports as is.

Mac or Linux?

Windows 10/11 only for now. The technology allows Mac and Linux builds: they will come if there is demand. Write to us if you need them.
