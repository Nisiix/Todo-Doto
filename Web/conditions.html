Conditions of use

Last updated: October 16, 2026

These conditions apply to downloading and installing Todo Doto from this website or from the Releases published in the GitHub repository, and supplement the Terms of use.

1. Download

The installers (.msi, setup .exe) and the executable are made available free of charge, in an Italian and an English edition: the language of the application is the one of the installer you download. Download the Application only from this website or from the official GitHub Releases: copies obtained elsewhere may have been altered. When available, check the fingerprints (checksums) published next to the files.

2. Requirements

  • Windows 10 or Windows 11, 64-bit.
  • Microsoft Edge WebView2 Runtime (included in recent Windows installations; the installer downloads it if missing).
  • For shared workspaces: a network folder reachable by all participants, with read and write permissions.

You are responsible for checking that your system meets these requirements and that the installation is allowed by your organization’s policies.

3. Installation and permissions

The installer writes the Application to the user’s programs folder and creates the start shortcuts. The Application needs read and write access to the workspace folders you choose and to the folders where you ask it to create a project folder (with “Create project folder”); if you use attachments, it opens files with the system programs. It does not change system settings, does not install auto-starting services and does not add browser components.

4. Windows warnings

Versions not signed with a recognized certificate may trigger the SmartScreen warning “Windows protected your PC”. This is normal for free software distributed without a paid certificate: you can proceed by choosing “More info → Run anyway”, after checking that you downloaded the file from the official sources.

5. Updates

The Application does not update itself. New versions are announced on the website and in the GitHub Releases; to update, install the latest version over the existing one. Workspace data are not touched by the update; a backup of the folder is still recommended.

6. Use on a company network

In a shared workspace every participant installs the Application on their own computer and opens the same network folder. Changes are written directly to the files: availability and performance depend on your network and server. If the folder cannot be reached, the Application reports the problem and retries, without losing changes already saved.

7. Uninstalling

You can uninstall the Application from Windows “Settings → Apps”. Uninstalling does not delete the workspaces (they remain in the folders you chose) nor the local data in %APPDATA%\com.nisos.projectgoalmanager, which you can delete manually.

8. Support

E-mail support at supporto@projectgoalmanager.app: within one business day for the Team plan, within four business hours for the Business plan, subject to availability for the Free plan. Bug reports and suggestions are also welcome in the project’s GitHub repository.

9. Liability

The limitations set out in the Terms of use apply. In particular, we are not liable for data loss due to failures, deletions, network conflicts or missing backups: back up the workspace folder regularly. The Italian version of these conditions is the authoritative one.
