Privacy policy

Last updated: November 24, 2026

This policy explains which data Todo Doto (the desktop application) and this website process, and how. The short answer: the application sends your data to no one; everything stays on your computer or in the shared folder you choose.

1. Controller

The data controller is the author of the Application, who can be contacted through the GitHub repository indicated on the website.

2. The desktop application

2.1 Data you enter

Projects, items, descriptions, questions, comments, attachments (as references to files or links), labels, project stack, workspace members and the activity log are saved as JSON files in the workspace folder. They are not transmitted to us or to any external service. In a network workspace they are accessible to the people who have access to that folder.

2.2 Local identity

To attribute changes, the Application reads the user name and computer name from the operating system and saves them in the workspace users file, together with the display name you choose. It does not collect e-mail addresses, phone numbers or other identifiers.

2.3 Workspace password

The password of a network workspace is stored in the workspace only as a hash (PBKDF2-SHA256 with a random salt). If you choose to remember it, on your computer it is stored encrypted with Windows DPAPI for your account (elsewhere with AES-GCM and a local key). Optionally the administrator can turn on data encryption on disk: all workspace files (except the settings needed to open it), the backups and the laptop copy are encrypted with AES-GCM 256 and a key protected by the workspace password.

2.4 Local data

In the user data folder (%APPDATA%\com.nisos.projectgoalmanager) the Application keeps: theme, list of recent workspaces, favorites, notification preferences, encrypted passwords, the encrypted OAuth credentials if you use Google Drive and, for network workspaces with “Keep a copy of the workspace on this PC” on, a copy of the workspace data to work when the shared folder is unreachable (encrypted like the workspace or with Windows DPAPI). The copy can be turned off in Settings. Notifications you receive stay in the Application’s local storage. Project folders you create with “Create project folder” are written only where you choose. You can delete everything by removing that folder.

2.5 Google Drive (optional)

If you connect a Google account, the Application talks directly to Google’s APIs from your computer, with your consent and with read-only permission (drive.readonly). Only the structure of the synced folder (names, identifiers, types and links of the files) is saved in the shared workspace, visible to the other members; the content of the documents is downloaded only when you open it and is not saved in the workspace. The access token stays encrypted on your computer. Google’s processing is described in Google’s privacy policy.

2.6 Email, Microsoft Teams, VPN and domain account (optional)

If the administrator configures them, the Application sends emails with the Outlook installed on the PC of whoever acts or with the company SMTP server (the SMTP password is stored in the workspace encrypted with the workspace password) and messages to a Microsoft Teams channel through a Workflow chosen by the administrator (Microsoft Power Automate addresses only). Messages contain the task title, project, who and what, due date and, only for whoever is mentioned, the comment text; never descriptions, attachments or paths. Each user chooses whether to enter their email and what to receive. The VPN is connected with the connections already configured in Windows, without the Application seeing the credentials. With company sign-in the Application reads the domain, SID and groups from the Windows account and stores the user's domain and SID in the workspace.

2.7 No telemetry

The Application contains no analytics, tracking or automatic error reporting tools and does not contact any server of ours. The only network connections are those to Google that you enable with the Drive feature, those for email and Teams configured by the administrator and, unless you turn it off (Settings › General), one request a day to GitHub to learn the latest published version: the request carries no data about you or your workspaces. “Send feedback” opens a GitHub page or your mail program only when you choose it, with the app and system version already filled in.

3. This website

The website is made of static pages. It uses no profiling cookies or third-party analytics tools. The light/dark theme and language preferences are saved in your browser (localStorage) and are not transmitted. Fonts are loaded from Google Fonts: in doing so, your browser sends your IP address to Google, according to Google’s policy. The download section may query the public GitHub API to find the latest release. The server hosting the website and any download server may record the IP address, date and time and requested page in technical logs, for security and maintenance, for the time strictly necessary.

Download counter. To know how many different devices download the Application, when you choose a file in the download section your browser creates a random code once, keeps it in its local storage (localStorage, key todo-doto:device) and sends it, together with the language, type and version of the file, to a function of ours hosted by Supabase (European Union). The server does not keep the code: it stores only a fingerprint keyed with a secret, which cannot be traced back to the code or to you, and it does not store your IP address or your browser. We use these data only in aggregate form (number of devices and of downloads per file), we do not combine them with other information and we do not share them with anyone; we delete them after 24 months. If you clear the site data in your browser, the code is removed and a later download counts as a new device. The download does not depend on the counter: it works even if sending fails.

4. Legal basis and retention

For the website, the processing of technical logs is based on the legitimate interest in ensuring its security and operation; logs are kept for a limited period. The download counter is based on the legitimate interest in knowing, in aggregate form, how widely the Application is used; its data are kept for 24 months. For the Application, data are processed exclusively on your devices and under your control: you decide where they are, who accesses them and how long to keep them.

5. Your rights

You have the right to access your data, rectify it, erase it, restrict its processing and object, as well as to lodge a complaint with the Italian Data Protection Authority (Garante per la protezione dei dati personali). For the Application’s data you can exercise these rights directly, because the files are yours; for the website logs you can contact us through the GitHub repository.

6. Children

The Application and the website are not intended for children under 14 and do not knowingly collect data about them.

7. Changes

We will update this policy if the features of the Application or of the website change; the date at the top shows the latest version. The Italian version of this policy is the authoritative one.
