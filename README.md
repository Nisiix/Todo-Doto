# Todo Doto

**Your projects’ roadmap, in a folder.** To-dos, priorities, due dates, questions and attachments, on your PC or in a shared network folder, with no server to install. Windows 10/11, free.

- **Download and guide:** https://nisiix.github.io/Todo-Doto/
- **All versions:** [Releases](https://github.com/Nisiix/Todo-Doto/releases) (installer, MSI and portable version for each language, with `SHA256SUMS.txt`)
- **Report a problem:** [Issues](https://github.com/Nisiix/Todo-Doto/issues/new/choose) · **Ideas and questions:** [Discussions](https://github.com/Nisiix/Todo-Doto/discussions)
